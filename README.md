# JavaScript Webpage Project - Personal Portfolio Website

Description

This is my personal portfolio website created using HTML, CSS, and JavaScript. It shows information about me, my skills so far, and three simple projects I have developed.

Features
* About me section
* Skills section
* Project card with images and Github links
* Dark mode option
* Welcome message modal
* Contact form (simulation)
* Session storage and JSON data handling

Languages Used
* HTML
* CSS
* JavaScript

You can visit the live deployment through GitHub Pages on the side or this link: https://ashermac17.github.io
